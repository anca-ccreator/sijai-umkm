# Panduan lokal G1-B3.4: verifikasi field

Ini hanya demonstrasi lokal dengan Unit, organisasi, petugas, field dan bukti yang semuanya sintetis. Buka halaman `/field/{id-aliran-field}` hanya setelah login dan konfirmasi kata sandi. ID aliran tidak disediakan oleh browser sebagai kewenangan; halaman tetap memeriksa sesi, mandat, cakupan, sensitivitas, tujuan dan masa berlaku di server.

Alur minimum adalah: pengusul mencatat nilai → pemeriksa menilai metadata bukti pada versi usulan → satu pengesah dari organisasi pemilik aktif menyetujui atau menolak. Usulan tidak mengubah nilai resmi. Nilai yang disetujui baru digunakan ketika tanggal efektifnya tiba. Pembatasan berjejak dapat menahan pemakaian karena sengketa, pencabutan atau risiko material.

Katalog bukti kosong, tidak berlaku, atau ambigu menghasilkan **BELUM DAPAT DINILAI**. Pengesahan C2 tidak mengesahkan field; NIB tidak menjadi syarat universal. Tidak tersedia tindakan ekspor/unduh atau unggahan dokumen.

Hal yang tidak termasuk: penetapan OPD/petugas/dokumen nyata, koreksi penuh K1–K4, profil pangan lengkap, koneksi audit eksternal, data historis/produksi dan deployment.
